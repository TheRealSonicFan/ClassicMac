# ClassicMac 4.4.0 validation

Published October 22, 2026 as stable Latest with ten assets, neither draft nor
prerelease. Exact source/tag: `15240410d2164a69f6af35765cf27ff102ae318d`
([PR #34](https://github.com/amcchord/ClassicMac/pull/34)).


The clean Mac OS 9.2.1 Library image now uses the emulated ATI Radeon with
Apple/ATI's native Mac OS software. GXMetal extensions, input/startup helpers,
diagnostics, the dormant NDRV transport and new download metadata are retired.
Historical release notes and evidence remain historical; obsolete installation,
status and game-sweep guides and their five screenshots are removed. Existing user machines are unchanged.

## Image qualification

The previous public clean template and Deluxe v9 were downloaded and checked
against the live catalog's SHA-256 values. Both source disks were mounted
read-only. A new filesystem copies approved system files, excluding retired
files before any write; source preferences, documents and free space are not
copied. The graphics donor supplies fourteen Apple/ATI components with both
forks verified by hash. Checked-in ClassicMac Display MacBinary helpers retain
both forks and Finder metadata. The new disk reaches Finder at 1024×768 using
Apple's ATI display driver and shuts down normally. Preparation guest exit is
explicitly verified. A second cold boot reaches Finder without a disk-check
dialog and exits normally after Shut Down. The initial v3 candidate was
withdrawn after a fresh import exposed a disk-check dialog: it had been
packaged before the preparation guest exited. Qualified v4 uses a new URL,
ID and checksum; the candidate is never overwritten. A read-only audit finds no
retired files; a scan of the full raw disk, including free space, finds zero
GXMetal byte strings. [Preparation](evidence/4.4.0/image-preparation.json),
[archive](evidence/4.4.0/clean-image.json),
[publication and rollback](evidence/4.4.0/image-publication.json).

The new immutable archive is published before the catalog's atomic promotion.
All other editions retain their existing values and archives. The live catalog
keeps a legacy `gxMetalVersion: "Unavailable"` marker solely for pre-4.4 app
catalog decoders; the app and new package/provenance no longer depend on it.
The new clean edition requires 4.4.0. Existing .classic packages are untouched.

## App and release gates

The PowerPC NDRV is rebuilt with the existing Retro68 toolchain after deleting
its dormant transport and registry header. Display mode and gamma tests pass.
New tests cover catalogs with/without the old metadata, old provenance, and
prepared ATI hardware on current/future clean image revisions. A path-sensitive
argument assertion now checks the actual VGA property rather than matching a
worktree's name. Sparse image preparation and package bounds tests pass.

The Mac app uses the checksum-verified public 4.3.0 runtime and its macOS 15
libraries, a fresh release Swift binary, updated versions, and the rebuilt
NDRV. The matching prepared QEMU source archive includes that NDRV. No emulation
CPU, sound or ATI implementation changes are included. The signed app and DMG
pass accepted notarization, stapling, Gatekeeper and the exact release verifier.

All 131 Swift tests pass (three local engine/optional Copland fixture skips).
All 21 desktop tests pass with a real signed qemu-img. The final notarized Mac
app downloads and verifies the public v4 image through the native setup wizard,
retains the ready screen, imports with ATI hardware and driver-neutral
provenance, and boots directly to Finder at 1024×768 with Tools mounted and
host 3D enabled. Host toolbar shutdown after Finder settles exits the emulator
and leaves HFS+ marked clean (`0x80000100`). Mac retains its existing 15-second
forced-stop fallback if the guest does not respond.

Native Linux run [39813549507](https://github.com/amcchord/ClassicMac/actions/runs/39813549507)
passes packaged boot, pause/resume, restart/reconnect, clean shutdown, toolbar
geometry and both first-run routes, including a real public v4 download,
pause/resume, checksum, preparation, ATI first Finder boot and clean shutdown.
Both platform packages contain all 57 current source/UI assets and the exact
rebuilt NDRV. Linux DEB/TAR application archives match. All three prepared
QEMU source archives contain the rebuilt NDRV and no retired transport files.
Current Deluxe v9 and SuperDeluxe v5 were independently hash-verified and
mounted read-only: both contain native ATI drivers and no GXMetal files.

Native Windows run [39814128066](https://github.com/amcchord/ClassicMac/actions/runs/39814128066)
also passes all 21 desktop tests, both packaged setup routes, real public v4
download/pause/resume/hash/import/first ATI Finder boot and normal shutdown,
and the existing standard-card boot/restart/reconnect/toolbar checks. Both
final runs use source `92b977dea514b3c07ee80b1746fdfe98b41049ee`; later commits
only add documentation, evidence and remove obsolete screenshots. Completed
job logs and uploaded reports are authoritative while GitHub status projections
lag. [Native gates](evidence/4.4.0/native-packages.json).

Consolidated root validation at that exact source passes 131 Swift tests
(two optional Copland fixture skips), all 21 desktop tests with the signed
image tool, all 15 Python preparation/packaging/library tests and both NDRV
mode/gamma contracts. [Integration](evidence/4.4.0/integration.json).

All nine archives were freshly downloaded anonymously and match the public
SHA256SUMS byte-for-byte. Public Latest metadata confirms stable 4.4.0 with ten
assets. The downloaded Mac DMG passes the full exact verifier, signatures,
staples and Gatekeeper. [Public verification](evidence/4.4.0/public-release.json),
[preflight](evidence/4.4.0/release-preflight.json),
[manifest](evidence/4.4.0/SHA256SUMS).
4.3.0 remains available for release rollback; restoring the checked catalog
backup rolls back downloads without changing installed machines. Windows
remains unsigned and Copland remains macOS-only.
