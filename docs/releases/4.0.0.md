# ClassicMac 4.0.0

ClassicMac 4.0 is the stable release of the Apple Platinum interface,
Mac OS Library and emulated ATI Radeon. Requires an Apple Silicon Mac
running macOS 15 or later. Download the DMG, open it and drag ClassicMac
to Applications. The ZIP is an alternative installation package.

- Reference screenshot tests cover 32 Platinum control states and patterns
  at 1× and 2×, plus all 95 printable system glyphs. The audit corrected
  gray levels, font widths, pop-up arrows and disabled/pressed artwork.
- Every window uses the Platinum appearance, including each running Mac’s
  screen, with sharp integer scaling, WindowShade, full screen and a lower
  toolbar for power, restart, pause, media and text paste.
- File → Mac OS Library offers ready-to-run Mac editions with resumable,
  verified downloads. Existing machine packages remain compatible.
- Power Macs can use an emulated ATI Radeon R100, accelerated through host
  OpenGL and driven by Mac OS 9’s own ATI software. Installer starts use
  the Standard card. GXMetal is retired in 4.0.
- Faster PowerPC emulation includes the VIA timer, Cuda handshake and IDE
  reset fixes qualified in Preview 3.
- Classic Macintosh machine icons by The Iconfactory are included with
  permission. Additional personal icon collections remain supported.

The app and DMG are Developer ID signed, Apple notarized and stapled.
Checksums and the corresponding Copland engine source accompany the release.
The [validation report](../4.0.0-validation.md) records testing and limits.

Copland D11E4 remains experimental, as in 3.2.1. ATI acceleration needs
Mac OS 9 ATI drivers and host OpenGL; unsupported hosts run with 3D off.
The downloadable catalog and existing machines are unchanged by this release.

Platinum fidelity work continues: some SwiftUI text is still smoothed, and
menus, scrollbars and whole-window states need additional native references.
The component tests are not a whole-application pixel-perfect certification.
