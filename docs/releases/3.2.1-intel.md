# ClassicMac 3.2.1 — Intel x86_64 release

This is the **Intel-only** binary release of ClassicMac 3.2.1.

## Compatibility

- Version: **3.2.1**
- Build: **3.2.1**
- Host architecture: **Intel x86_64 only**
- Minimum host OS: **macOS 15**
- QEMU: **11.0.2 (ClassicMac custom build)**
- Signing: **ad-hoc**
- Notarization: **not notarized**
- Apple Silicon: **no arm64 binary is included in this release**
- Source builds: the repository can still be built natively for arm64 on Apple Silicon.

The packaged release was verified with the repository's ad-hoc release verifier.
It passed DMG integrity/signature checks, deep app signature validation, hardened
runtime checks, QEMU JIT entitlement checks, native x86_64 architecture checks,
GXMetal/QEMU feature checks, and macOS 15 runtime-library compatibility checks.

### ClassicMacTools.iso

- Size: **33,554,432 bytes (32.00 MiB)**
- SHA-256:
  `8c99d6972b365778a51bd986a416ecbbcb91507b53b767463e0c176d78240bc5`
- Layout: **Apple Partition Map + HFS (Mac OS Standard)**
- Volume: **ClassicMac Tools**

`ClassicMacTools.iso` mounts within a **Mac OS 9 VM**. It does **not** mount
on modern macOS because the image uses HFS (Mac OS Standard), which modern
macOS no longer supports for mounting. Attach it to the emulated Mac instead.

The app also bundles the same Tools image and automatically exposes it to
supported Power Mac guests.

## Guest additions

The Tools image contains GXMetal 2.3.0 and classic-Mac utilities prepared so
their resource forks and Finder metadata survive on the HFS volume.

GXMetal components include:

- GXMetal
- GXMetal Input
- GXMetal Startup
- Install GXMetal
- GXMetal Test
- GXMetal AGL Probe
- GXMetal RAVE Selection
- GXMetal Read Me

Additional classic-Mac tools include:

- Apple HD SC Setup (patched)
- Lido 7.56
- StuffIt Expander 5.5
- DropStuff 5.5 Installer
- USB Overdrive 1.4
- Disk Copy 6.3.3
- Virtual CD-DVD Utility
- Transmit 1.6 PPC
- Transmit 1.6 68k

## Emulated systems

ClassicMac provides:

- Macintosh Quadra 800 for System 7.1 through Mac OS 8.1
- Power Mac G4 for Mac OS 8.5 through Mac OS 9.2.2
- Experimental Copland D11E4 preview through the Power Mac 7500 engine

QEMU remains TCG-based. GXMetal remains available on supported Mac OS 9 guest
configurations and uses the host Metal backend where supported.
