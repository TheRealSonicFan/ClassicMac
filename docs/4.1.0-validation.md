# ClassicMac 4.1.0 stable release

Published October 18, 2026 as GitHub stable Latest:
[ClassicMac 4.1.0](https://github.com/amcchord/ClassicMac/releases/tag/v4.1.0).

## Support and rollback

Windows binaries are unsigned. Linux requires x64/glibc 2.39+ and host
desktop/audio/GPU drivers. Copland remains macOS-only; Windows 9p sharing is
unavailable. Physical GPU/audio output, Internet browsing and a game suite
were not qualified on the virtual hosts. The full interface and shared CSS
frontend are not certified pixel perfect; the Mac audit covers its documented
32 component references at 1×/2× and 95 system-font glyphs/advances.

Previous releases and assets remain available; v4.0.0 is the immediate rollback
for Mac. If a release problem warrants rollback, set 4.0.0 as GitHub Latest
and update the 4.1 release notes while retaining its evidence. The Library
catalog and existing user machines were not changed. No unrelated Proxmox VM
or template was modified. Dedicated test hosts are retained for future work;
Windows auto-login was disabled and its registry password removed after tests.

Fresh downloads of all nine public archives match the published SHA256SUMS.
The fresh public Mac DMG passes staple validation, Gatekeeper and full
`verify-release.sh` against integrated source and the qualified Tools CD.
GitHub's latest-release API confirms `v4.1.0`, `draft=false`,
`prerelease=false`, with all ten assets (including SHA256SUMS).
