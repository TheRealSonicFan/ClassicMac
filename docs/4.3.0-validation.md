# ClassicMac 4.3.0 validation

Published October 22, 2026 as stable Latest with ten assets, neither draft nor
prerelease. Exact source/tag: `7467ddd02d03cc66360273de252b9db123124cfa`.
The tested PR #33 head was merged through Git while GitHub’s PR status
processing was degraded. The merge tree exactly matches the qualified branch.

Fresh anonymous downloads of all nine archives match the public SHA256SUMS.
[Public verification](evidence/4.3.0/public-release.json) and
[exact preflight](evidence/4.3.0/release-preflight.json) retain the evidence.

First-run setup is now a four-step flow on macOS, Windows and Linux: license
responsibility, source choice, preparation and ready. Existing libraries open
normally. Software licensing responsibility stays with the user; downloading
a pre-installed machine does not grant licenses.

## Scope and checks

The signed Mac app was tested with disposable homes and machine folders. The
real Library's clean Mac OS 9.2.1 entry downloaded, passed SHA-256 verification,
installed and reached the ready screen without losing the wizard when the
machine registered. Start Mac reached the Finder desktop; the guest shut down
normally. The own-CD path required a CD, copied a real OS 9.2.1 installer image,
created a sparse 32 GB disk with recommended defaults, and Start Installer
booted that CD to its desktop. The ready page and home panel show installation
instructions. This test stops before running the guest OS installation.

130 Swift tests pass. Two optional Copland fixture tests and the development
qemu-img sparse-image test are skipped in the isolated task checkout; the
consolidated integration run and the desktop tests cover sparse disk creation.
20 desktop tests pass using the real bundled image tool, including both
machine families, copied-CD startup defaults, non-colliding package names,
and cleanup after failed creation. Browser checks cover the license gate,
no catalog request before choosing download, newest available editions,
pause/resume, download/start, installer/create/later and existing libraries.

Native Windows/Linux packaged CI adds first-run renderer/IPC checks using
isolated Documents directories. The CD test substitutes the file picker with
a disposable copy fixture; actual disk and CD creation use shipping handlers.
The download test uses the real clean Library entry, pauses/resumes it, then
checks the ready screen, Start Mac, Finder framebuffer and clean shutdown.
Existing packaged boot/pause/resume/restart/shutdown and toolbar checks remain.
The first Linux restart caught an occupied display port. Startup now retries
that specific pre-boot bind failure at most three times; injected-process tests
prove retry bounds and immediate reporting of unrelated errors.
Default-sound setup checks exposed hosts without usable PulseAudio or
DirectSound output. A recognized host-audio startup failure now retries once
with a silent backend for the session, preserving the guest sound hardware
and saved preference. The app reports sound unavailability. Native CI
qualifies this path; no virtual audio service is required. Windows
qualification caught an unsupported raw preallocation option; Windows now
uses its supported default raw-create options in both setup and New Mac. A
platform-specific regression check covers those arguments. Windows packaging
also requires its unit tests to pass before it can build an archive.
Final native packaged runs [Linux 39806241075](https://github.com/amcchord/ClassicMac/actions/runs/39806241075)
and [Windows 39806245692](https://github.com/amcchord/ClassicMac/actions/runs/39806245692)
pass at source `49dd7ded0b42ffacb6937b5c538de40a4268002b`. Completed job logs
and uploaded reports prove all 20 desktop tests, both setup routes, default
audio fallback, first Finder boot and clean shutdown. Existing smoke checks
include pause/resume, restart/reconnect and toolbar geometry. All 57 packaged
source/UI files match on each platform (normalizing Windows text line
endings), and DEB/TAR application archives match.
GitHub’s Actions/PR incident temporarily left the visible run statuses stale. The same shipped
renderer/IPC tests also pass locally in Electron on macOS, including real
Library pause/resume, first Finder boot and normal shutdown.

The Mac package uses fresh public 4.2.0 engines and their corresponding source
archives. All four engine Mach-O code images match exactly after excluding
code signatures and normalizing LC_CODE_SIGNATURE fields; only bundle version
metadata/signatures and the app executable change. No emulation patch or guest
software ships in this release. Newer Deluxe/SuperDeluxe catalog revisions use
ATI Radeon hardware defaults with current catalog descriptions.

## Release gates

Mac app/DMG signing, accepted notarization/staples, Gatekeeper and exact
verify-release checks pass. Final notarized-app Finder boot, existing-library
bypass and normal shutdown pass. Native package gates and archive hashes pass.
Consolidated root validation at the exact release source passes 130 Swift
tests (two optional Copland fixture skips) and all 20 desktop tests with the
real image tool. [Integration results](evidence/4.3.0/integration.json). All nine
fresh anonymous archive downloads match the published manifest; the public
Latest API confirms stable 4.3.0. The downloaded Mac DMG passes the full
release verifier, Gatekeeper and staple validation. Stable 4.2.0 and its
assets remain available. Rollback promotes v4.2.0 to Latest with
`gh release edit v4.2.0 --latest` and records the reason in the 4.3 notes.

Windows remains unsigned; Copland remains macOS-only. Physical Windows/Linux
GPU/audio behavior and exhaustive guest installation are outside this setup
qualification. No Library catalog, hosting, DNS or infrastructure changes.
