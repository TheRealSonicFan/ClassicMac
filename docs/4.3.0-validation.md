# ClassicMac 4.3.0 validation

First-run setup is now a four-step flow on macOS, Windows and Linux: license
responsibility, source choice, preparation and ready. Existing libraries open
normally. Software licensing responsibility stays with the user; downloading
a pre-installed machine does not grant licenses.

## Scope and checks

The signed Mac app was tested with disposable homes and machine folders. The
real Library's clean Mac OS 9.2.1 entry downloaded, passed SHA-256 verification,
installed and reached the ready screen without losing the wizard when the
machine registered. Start Mac reached the Finder desktop; the guest shut down
normally. The own-CD path required a CD, copied a real OS 9.2.1 installer image,
created a sparse 32 GB disk with recommended defaults, and Start Installer
booted that CD to its desktop. The ready page and home panel show installation
instructions. This test stops before running the guest OS installation.

130 Swift tests pass. Two optional Copland fixture tests and the development
qemu-img sparse-image test are skipped in the isolated task checkout; the
consolidated integration run and the desktop tests cover sparse disk creation.
15 desktop tests pass using the real bundled image tool, including both
machine families, copied-CD startup defaults, non-colliding package names,
and cleanup after failed creation. Browser checks cover the license gate,
no catalog request before choosing download, newest available editions,
pause/resume, download/start, installer/create/later and existing libraries.

Native Windows/Linux packaged CI adds first-run renderer/IPC checks using
isolated Documents directories. The CD test substitutes the file picker with
a disposable copy fixture; actual disk and CD creation use shipping handlers.
The download test uses the real clean Library entry, pauses/resumes it, then
checks the ready screen, Start Mac, Finder framebuffer and clean shutdown.
Existing packaged boot/pause/resume/restart/shutdown and toolbar checks remain.
Final run IDs and outcomes are recorded after completion.

The Mac package uses fresh public 4.2.0 engines and their corresponding source
archives. All four engine Mach-O code images match exactly after excluding
code signatures and normalizing LC_CODE_SIGNATURE fields; only bundle version
metadata/signatures and the app executable change. No emulation patch or guest
software ships in this release. Newer Deluxe/SuperDeluxe catalog revisions use
ATI Radeon hardware defaults with current catalog descriptions.

## Release gates

Signing, notarization/stapling, Gatekeeper, exact package verification, native
CI, integration tests, archive hashes and anonymous public-download checks
must pass before recording this release as published. Stable 4.2.0 and its
assets remain available. Rollback promotes v4.2.0 to Latest with
`gh release edit v4.2.0 --latest` and records the reason in the 4.3 notes.

Windows remains unsigned; Copland remains macOS-only. Physical Windows/Linux
GPU/audio behavior and exhaustive guest installation are outside this setup
qualification. No Library catalog, hosting, DNS or infrastructure changes.
