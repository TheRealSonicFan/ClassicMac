# ClassicMac 4.0.0 qualification

Host: Apple M5 Max, macOS 27.2. Build and deployment target: Apple Silicon,
macOS 15 or later. Final evidence: root `output/4.0.0/`. Earlier artwork/boot evidence is in
`worktrees/4.0-stable-release/output/4.0.0/`.

## Source and changes

Release source: `cee04d02994314e5345d2f1c6608e4721f580687` (`v4.0.0`).
Baseline main `8bf3632` (4.0 Preview 3). Engine, CPU, firmware, guest drivers
and Tools CD are unchanged from that qualified preview. The release rebuilds
the Swift application, bundles Iconfactory machine artwork and its attribution,
updates the default package version to 4.0.0 and extends release verification.
PR #25 adds the reference-backed Platinum control/font corrections and image
regression gate; see `platinum-fidelity-audit.md` for coverage and remaining gaps.
Prepared engines and their licenses are read in place from the 4.0 engine
worktree using `VENDOR_DIR`; no dependency tree is copied or modified.

The three original icns resources come from Austin’s `download.dmg` and
`download-2.dmg`, mounted read-only. Their hashes and original names are in
`Resources/Iconfactory/manifest.json`; original licenses and readmes accompany
them. Austin explicitly confirmed permission to include them on October 18.
Imported personal collections override built-ins; removing imports restores
the included icons.

## Verification

- Swift suite: 122 tests, zero failures, two fixture-dependent skips in the final
  integration checkout (Copland lifecycle and real machine import). The
  isolated audit worktree also skips a local preview fixture.
- Included artwork decodes at both native 16×16 and 32×32 sizes for every
  model; visible pixels and dimensions are checked.
- Signed packaged app passes `verify-release.sh`: Developer ID/hardened
  runtime, complete resources, exact artwork/attribution, no GXMetal,
  ATI/Standard devices, native/browser displays, no external library paths,
  all packaged runtime libraries target macOS 15 or earlier.
- Packaged ATI realization test passes: host GL renderer is Apple M5 Max;
  disabling 3D works; Standard VGA realizes.
- Packaged display protocol gate passes: greeting, shared framebuffer,
  damage/events and reconnect.
- Disposable machine copies, isolated from the user library: Deluxe boots
  on ATI to a 1024×768 Finder in its Platinum window. The library displays
  included Iconfactory icons with no imported collections. Mac OS 9.2.1
  also boots with Standard graphics to a 1024×768 Finder; both Macs finish
  the scripted Shut Down sequence. Final icon-dialog screenshots show all
  three bundled icons and their credits.

Published GitHub stable Latest `v4.0.0` on October 18, 2026. Both the app
and DMG were accepted by Apple's notary service and stapled. Gatekeeper and
`verify-release.sh` pass on the DMG and on a fresh public download. The final
rebuilt app again booted both disposable ATI and Standard Macs to Finder and
completed normal shutdown; all three included icons are visible in the dialog.

## Limits

Preview 3’s engine soak and compatibility evidence remains applicable;
see the engine and startup-race reports. No new full game sweep, Intel host,
physical macOS 15 host or long sound/networking soak was performed for this
artwork/package change. Copland remains experimental. A scripted window tour
is not a complete human interaction walkthrough.

Rollback: retain Preview 3 and stable v3.2.1 and their assets. If required,
mark the 4.0 release as a prerelease and restore v3.2.1 as GitHub Latest.
No download catalog or existing user machine is changed.
